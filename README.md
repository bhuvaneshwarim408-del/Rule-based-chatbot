# CodSoft AI Internship - Task 1

## Rule-Based Chatbot

A simple chatbot built in Python that responds to user messages based on keyword matching.

### Features
- Greets the user
- Responds to questions about its name
- Answers "how are you"
- Says goodbye and exits on command

### How to run
python chatbot.py
