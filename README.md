# CodSoft AI Internship - Task 1

## 🤖 Rule-Based Chatbot

A simple interactive chatbot developed using Python as part of my CodSoft Artificial Intelligence Internship.

The chatbot uses **keyword matching and conditional statements** to identify common user inputs and provide appropriate responses.

## 🎯 Objective

The objective of this project is to build a simple rule-based chatbot that can interact with users, recognize predefined keywords, and respond to common questions and commands.

## ✨ Features

* Greets the user
* Responds to greetings such as "hi", "hello", and "hey"
* Responds when the user asks for its name
* Answers "how are you"
* Provides help and usage instructions
* Responds to questions related to college
* Handles goodbye commands such as "bye", "exit", and "quit"
* Provides a default response when it does not recognize the input
* Converts user input to lowercase for easier keyword matching
* Removes unnecessary spaces from user input

## 🧠 How It Works

This chatbot is a **rule-based system**. It does not use machine learning or a pre-trained language model.

The chatbot follows these steps:

1. Takes input from the user.
2. Converts the input to lowercase.
3. Removes extra spaces.
4. Checks the input for predefined keywords.
5. Matches the input with appropriate conditions.
6. Returns a suitable response.
7. Continues the conversation until the user enters a goodbye command.

## ▶️ How to Run

### Step 1: Install Python

Make sure Python 3 is installed on your computer.

Check the Python version using:

```bash
python --version
```

### Step 2: Clone the Repository

Open Command Prompt or Terminal and run:

```bash
git clone https://github.com/bhuvaneshwarim408-del/codsoft_task1.git
```

### Step 3: Open the Project Folder

```bash
cd codsoft_task1
```

### Step 4: Run the Chatbot

```bash
python Chatbot.py
```

The chatbot will start running in the command-line interface.
